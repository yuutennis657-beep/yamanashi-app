# イーハトーヴの谷 〜やまなし〜（見本）

小学6年生の国語「やまなし」（宮沢賢治）の学習アプリの見本です。
1つのHTMLファイルだけで動き、子どもはChromebookにダウンロードして開いて使います。

▶ 開く：https://yuutennis657-beep.github.io/yamanashi-app/

## ためし方

**スマホのとき**（はじめに 案内が 出ます）

1. Safari で ひらく（LINE などの 中で ひらいたときは「Safari で 開く」）
2. 共有ボタン □↑ →「ホーム画面に追加」
3. ホーム画面の「やまなし」から ひらいて、スマホを よこに する

PC・Chromebook と 同じ 画面が、そのまま ちぢんで 出ます。字が 小さいときは 指で 広げて 見られます。

**アプリの中で**

1. 組・番・名前は 見本の「1組1番 みほん はなこ」が 入っています。そのまま「谷へ もぐる」
2. 谷マップから、第1〜9時の学習や「みんなの広場」「じぶんの学び」などを開けます
3. 先生用のパネルは「めあてとあゆみ」の画面の 🔑 から。見本のあんしょう番号は **0000** です

## 見本について

- 書いたものは、開いたブラウザの中にだけのこります。どこにも送られません。
- 実際の授業では、提出・みんなの広場・音読を学校のGoogleフォームとApps Scriptにつないでいます。見本ではその送り先をすべて外してあるので、「みんなの広場」は空のままで、提出ボタンを押すと「送る用意がまだできていない」と出ます。
- 子どもの名前・作品、学校や先生の名前は入っていません。
